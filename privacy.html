Privacy Policy

Who uses Clip Machine

Clip Machine is a personal tool. The only accounts connected to it are its developer's own TikTok and YouTube accounts.

What it accesses

When an account is connected, Clip Machine receives an access token from TikTok or Google that lets it upload videos to that account. On TikTok it also reads the basic creator information needed to post (username and allowed privacy settings). It reads nothing else from the account.

Where data is kept

Access tokens and the posting schedule are stored only on the computer running Clip Machine. Nothing is sent to any server other than TikTok and YouTube, and nothing is shared with or sold to third parties. Clip Machine has no analytics and no tracking.

YouTube API Services

Clip Machine uses YouTube API Services to upload videos. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time in the Google security settings and in the TikTok app under Settings, Security and permissions, Manage app permissions. Deleting the token files on the computer removes all stored data.
